## ✨ Features

- ⚡ Fully responsive design (mobile, tablet, desktop)
- 🎨 Clean, modern UI with consistent design system
- 🧭 Fixed navbar with smooth scroll and active link indicator
- 🦸 Hero section with stats, social links, and profile image
- 🧠 Skills section with categorized tech tags
- 💼 Experience timeline with role, company, and tags
- 🔬 Research papers with conference badges
- 💻 Development projects with live demo links
- 🎓 Education timeline
- 🏆 Awards & Achievements
- 🎖️ Leadership & Extracurricular roles
- 📜 Certifications
- 📬 Footer with contact details and quick links

## 🚀 Getting Started

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/naharluna/portfolio.git

# Navigate into the project
cd portfolio

# Open in browser
open index.html
```

Or simply open `index.html` directly in your browser — no build tools or dependencies required.
